# Script Praktikum Pemrograman Lanjut

Folder ini berisi salinan contoh program dari `belajar_oop_php` yang telah dipetakan ulang mengikuti Sub-CPMK dan urutan materi di folder `Modul`.

## Aturan penggunaan

1. Buka folder minggu yang sesuai dengan modul perkuliahan.
2. Jalankan contoh berdasarkan nomor folder topik dan nomor file.
3. File yang mengandung kata `error` atau `problem` memang disediakan sebagai contoh masalah; bandingkan dengan file solusi setelahnya.
4. Contoh database memerlukan MySQL/MariaDB dan penyesuaian kredensial koneksi lokal.
5. Materi evaluasi pada Minggu 8 dan 16 tidak memiliki contoh program baru.

## Catatan cakupan

Materi sumber yang tidak tercantum pada modul terbaru tidak dimasukkan, misalnya namespace, autoloading, trait, magic method, DateTime, dan aplikasi akhir stock manager. Dengan demikian, isi `Script` tidak memperluas Sub-CPMK di luar peta pembelajaran.

Seluruh file sumber tetap tersedia pada `belajar_oop_php`; struktur ini adalah salinan terpilah untuk kegiatan perkuliahan.
