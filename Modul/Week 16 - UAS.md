# MODUL PERKULIAHAN

## Mata Kuliah: Pemrograman Lanjut

### Minggu Ke-16: Ujian Akhir Semester (UAS)

# 1. CAKUPAN EVALUASI

UAS mengukur kemampuan mahasiswa mengintegrasikan OOP, akses database menggunakan PDO, query builder, exception handling, dan validasi class dalam satu studi kasus.

# 2. BENTUK EVALUASI

Evaluasi berupa proyek *case method*, demonstrasi, dan/atau ujian praktik sesuai kontrak perkuliahan. Tidak ada materi baru pada minggu ini.

# 3. KRITERIA UMUM

1. Ketepatan penerapan konsep OOP.
2. Keamanan dan ketepatan akses database.
3. Kualitas query builder dan pemisahan tanggung jawab class.
4. Ketepatan validasi dan penanganan exception.
5. Keterbacaan kode dan kemampuan menjelaskan hasil implementasi.
