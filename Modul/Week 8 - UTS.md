# MODUL PERKULIAHAN

## Mata Kuliah: Pemrograman Lanjut

### Minggu Ke-8: Ujian Tengah Semester (UTS)

# 1. CAKUPAN EVALUASI

UTS mengukur ketercapaian Sub-CPMK Minggu 1–7:

1. Konsep dasar objek, class, atribut, dan method.
2. Penerapan class, constructor, dan method.
3. Encapsulation dan access modifier.
4. Inheritance, polymorphism, abstraksi, dan interface.
5. Exception handling dan MySQLi Object.

# 2. BENTUK EVALUASI

Evaluasi dapat berupa tes tertulis, praktik pemrograman, atau studi kasus sesuai kontrak perkuliahan. Tidak ada materi baru pada minggu ini.
